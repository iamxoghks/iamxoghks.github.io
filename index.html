01

Tantan github.com/beyond-sw-camp/be23-2nd-team1-tantan-be

접속 상태, 메시지 동기화, 푸시 전달을 다루는 실시간 채팅 백엔드.

백엔드 설계 결정
  • 실시간 전송을 위한 WebSocket과 STOMP
  • 접속 상태, 세션, 안 읽은 메시지 카운터를 위한 Redis
  • 핵심 채팅 읽기/쓰기 분리를 위한 MySQL
  • 알림과 분석 이벤트를 위한 Kafka
배운 점
  • Offset pagination은 규모가 커질수록 깨지기 쉽다
  • Cursor indexing은 읽기 성능을 안정적으로 만든다
  • 실시간 기능은 실패 경로를 초기에 설계해야 한다

이벤트 흐름

client -> api -> kafka(chat.message.new)
consumer -> push service / analytics
02

Atlas github.com/beyond-sw-camp/be23-fin-team1-Atlas-be

검색, 분석, A/B 테스트를 포함한 확장 가능한 콘텐츠 플랫폼 백엔드.

백엔드 설계 결정
  • 전문 검색을 위한 Elasticsearch
  • 조회와 이벤트 수집을 위한 Kafka
  • 높은 쓰기 처리량을 위한 MySQL partitioning
  • 인기 콘텐츠와 카운터를 위한 Redis cache
배운 점
  • 읽기는 denormalize하고, 쓰기는 단순하게 유지한다
  • 최적화 전에 먼저 측정한다
  • 검색 관련도에는 피드백 루프가 필요하다

03

MHiT github.com/beyond-sw-camp/be23-1st-wow-MHiT

FHIR 스타일 API와 감사 로그를 갖춘 헬스케어 데이터 통합 플랫폼.

백엔드 설계 결정
  • Java Spring 기반 modular monolith
  • 관찰 데이터 확장을 위한 DTO column 설계
  • 신뢰 가능한 이벤트 처리를 위한 Kafka outbox pattern
  • 대용량 리소스 전달을 위한 presigned URL
배운 점
  • 감사 가능성은 제품 기능이다
  • 멱등성은 설계 단계에 포함되어야 한다
  • 헬스케어 데이터에는 보수적인 기본값이 필요하다

GET   /audit/logs?resource={type}&id={id}

(analytics / notifications / audit)
